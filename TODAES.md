# TODAES Experiments

To reproduce the experiments, run this script:

```shell
./run_todaes_experiments.sh [num_parallel_jobs]
```

Results are in `vtr_flow/tasks/TODAES_TASKS/<task>/run00X/parse_results.txt`, where `<task>` is one of
`10um_bidir_interposer`, `10um_unidir_interposer` or `10um_varlen_interposer`.
